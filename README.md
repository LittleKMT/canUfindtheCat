# Can You Find the Cat?

A mobile-friendly hidden-object game built from 70 original picture puzzles with 445 hidden cats.

## Play

Open the GitHub Pages URL shown in the repository details.

## Features

- 20 monochrome four-cat levels, 15 colorful classic levels, and 35 ten-cat challenge levels
- 445 hidden cats in total with five-heart scoring
- Thirty-five dense challenge scenes with exactly ten cats in every picture
- Three extra-hard scenes with tiny cats, irregular spacing, close pairs, and edge hiding spots
- Only the cat you find changes to orange
- Switch between black-background/white-line and white-background/black-line views
- Hint lens, pinch zoom, pan, and reset view
- Responsive phone and desktop layout
- Progress, best time, and stars saved locally
- Lightweight static site with no build step

## Local preview

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080`.

All puzzle artwork in this repository is original project artwork.
